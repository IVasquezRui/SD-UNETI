# UNETI Design System - Modernization Project

## 🎨 Paleta de Colores (Enfoque Minimalista)
- **Fondo Principal (White):** `#ffffff` - Color dominante para proporcionar limpieza y modernidad.
- **Acción Principal (Orange):** `#ef5b2b` - Color de acento exclusivo para CTAs de alta prioridad (Admisiones, Aula Virtual).
- **Identidad Base (Navy Blue):** `#162953` - Uso discreto en textos de jerarquía y elementos estructurales.
- **Acentos Funcionales (Uso Discreto):**
  - **Teal (#19a6b3):** Micro-interacciones e iconos secundarios.
  - **Purple (#4e1d5f):** Detalles en secciones académicas.
  - **Amber (#fbb41a):** Resaltado sutil de información.
  - **Green (#1da448):** Indicadores de éxito o sostenibilidad.

## 🔡 Tipografía
- **Fuente:** Hanken Grotesk (Sans-serif tecnológica).
- **Escala:**
  - H1: 3.5rem (bold, tracking tight)
  - H2: 2.25rem (semibold)
  - Body: 1rem (regular, leading relaxed)

## 🏗️ Componentes (Shadcn/ui + Tailwind)
- **Botones:** Bordes redondeados (`rounded-md`), sombra sutil, transición suave.
    - **Botones Primarios:** Fondo `#ef5b2b`, texto blanco, hover `#d9481d`.
    - **Botones Secundarios:** Fondo blanco, texto negro, hover `#fbb41a`.
- **Cards:** Fondos blancos, bordes mínimos (`border-slate-100`), elevación suave al hacer hover.
- **Layout:** Contenedores con max-width de 1440px y espaciado generoso (whitespace).

## ⚖️ Normativas
- **Accesibilidad:** Contraste verificado para textos sobre fondo blanco.
- **Gov Tech:** Alineación con estándares del Gobierno Bolivariano de Venezuela.
- **ISO 9001:2015:** LaUniversidad Nacional Experimental de la Seguridad se rige por la norma ISO 9001:2015, por lo que el diseño de la página web debe reflejar los principios de calidad, transparencia, y mejora continua.
- **Manual de Identidad Visual de la UNETI:** Debe seguir el Manual de Identidad Visual de la UNETI, el cual se encuentra en el repositorio y define los colores, tipografías y logotipos que deben utilizarse en la página web.

## 🏗️ Estructura del Proyecto
```
@/components/ui             # Componentes Shadcn/ui
@/components/layout         # Estructura del sitio (Header, Footer, Sidebar)
@/components/widgets        # Componentes específicos del dominio (Carreras, Noticias)
@/lib/utils                # Utilidades TypeScript (formatos, validaciones)
@/app/[locale]             # Rutas del App Router (interfaz multi-idioma)
@public                    # Assets estáticos y logos institucionales
```

## ❌ Errores Comunes a Evitar
- **No saturar el diseño:** El blanco debe ser el color dominante.
- **No sobrecargar de elementos:** El espacio en blanco es una herramienta de diseño fundamental para la claridad institucional.
- **No usar colores vibrantes en textos:** El texto debe ser de color negro o gris oscuro para facilitar la lectura.
- **No usar colores vibrantes en fondos:** El fondo debe ser de color blanco para facilitar la lectura.
- **No usar colores vibrantes en botones:** Los botones deben ser de color blanco con bordes de color negro para facilitar la lectura.
- **No usar colores vibrantes en cards:** Las cards deben ser de color blanco con bordes de color negro para facilitar la lectura.
- **No usar colores vibrantes en iconos:** Los iconos deben ser de color negro para facilitar la lectura.
- **No usar colores vibrantes en animaciones:** Las animaciones deben ser suaves y sutiles para no distraer al usuario.
- **No usar colores vibrantes en tipografía:** La tipografía debe ser de color negro o gris oscuro para facilitar la lectura.
- **No usar colores vibrantes en layout:** El layout debe ser limpio y ordenado para facilitar la navegación.
- **No usar colores vibrantes en herramientas:** Las herramientas deben ser de color negro o gris oscuro para facilitar la lectura.
- **No usar colores vibrantes en implementación:** La implementación debe ser limpia y ordenada para facilitar la lectura.
- **No usar colores vibrantes en notas:** Las notas deben ser de color negro o gris oscuro para facilitar la lectura.
- **No usar colores vibrantes en errores:** Los errores deben ser de color negro o gris oscuro para facilitar la lectura.
